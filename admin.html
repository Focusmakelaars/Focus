GitHub-token instellen

Om te kunnen publiceren heeft de editor eenmalig een GitHub-token nodig. Dat blijft alleen in deze browser bewaard.

  1. Log in op GitHub als Focusmakelaars
  2. Ga naar Settings → Fine-grained tokens
  3. Repository access: Only select repositories → Focusmakelaars/Focus
  4. Permissions → Contents: Read and write
  5. Genereer en plak het token hieronder
